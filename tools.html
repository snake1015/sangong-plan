09 · 可打印工具包

6张自带分页的模板：自检表、周节奏表、学期规划、五年级冲刺月历、材料核对、三校对比。

09 · 可打印工具包：把清单贴到冰箱上

下面是 6 张可直接打印的空白模板，每张自带分页。建议：一张总表贴书桌，一套文件袋每学期归档——任何一张表坚持用两学期，都胜过十张摆设。

🍼

0–6 岁启蒙自检表

每半年一张，身体/语言/习惯/兴趣四大栏打勾，发现偏科早补救。

 🗓️

每周节奏表（空白版）

周一到周日×时间段的空白格，全家一起排，先填睡眠与运动。

 📚

学期规划页

每学期一张：目标 / 三科重点 / 书单 / 参赛考证计划 / 期末复盘。

 🚀

五年级“决战2035”逐月行动表

2034.9–2035.6 每月一栏：材料→报名→评估→放榜，逐月勾选不焦虑。

 📁

三公报名材料核对表

4 月报名前逐项打勾：证件 / 成长手册 / 证书扫描 / 自荐信息，永不漏件。

 ⚖️

三校对比决策表

学制 / 出口 / 通勤住宿 / 孩子匹配度逐项打分，帮全家做选择。
打印技巧：电脑/手机浏览器打开 printables.html → Ctrl/Cmd+P → 目标打印机 → “背景图形”可选开 → 每张工具表会自动分页。 低年级阶段用不到的表（如五年级行动表）可以先存着，别一次全打印，省纸也省心。
