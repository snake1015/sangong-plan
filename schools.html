05 · 三所学校档案（附2026年官方招生意）

以下“2026招生意 / 流程”均对照三校官方2026年招生简章整理。数字每年4月刷新，这里提供的是“看门道”的方法与最新样例。

上海市实验学校（上实）

公办 · 全市唯一学制改革特色实验项目学校 · “十年一贯”（约10年完成小学至高中课程）

身份与学制

  • 学制：小学4年 + 初中3年 + 高中3年（官方口径“十年一贯制”），学生整体比同龄人更早毕业；
  • 出口：本校直升体系为主 + 对外招高中（高中阶段以学校官方口径为准）；
  • 特色：理科/科创氛围浓；2025年起媒体报道开设“数学班”“信奥班”方向（机构整理，非简章明文）；
  • 2026招生意：小学一年级 60 名（学制四年）+ 初中一年级 140 名（学制三年，含预初）——两条对外通道；
  • 地址/电话：小学部 浦东南码头路1316弄1号（50866068）；初中部 浦东东明路300号（50866819）；
  • 官网/报名：sesedu.cn ｜ 报名通道 sesedu.cn/enroll、ses.pudong-edu.sh.cn/enroll

初中部报名要求（2026官方原文要点）

  • 对象：本市当年小学毕业生；
  • 条件：①品德优秀；②小学生成长记录手册（四至五年级）综合素质优秀；③较强逻辑思维、语言表达、想象与组织协调能力；
  • 流程：网上登记（约4月10–15日）→ 4月15日16:00后查审核结果 → 通过者参加学校评估 → 公示录取；
  • 2026年初中评估日期：简章未提前公布，由学校另行通知；
  • 小学部（幼升小）特殊点：网上登记后摇号确定入围名单（2025/2026年如此），入围者再参加评估。
适合谁：孩子聪慧早熟、坐得住、爱钻研、家庭认同“压缩学制”的成长节奏。
注意：学制特殊意味着比同龄人更早面临升学分流，选择前请务必与学校核实学制与出口细节；“摇号定入围”意味着报名量大时实力未必有展示机会（拼运气+拼实力双重机制）。

上海外国语大学附属外国语学校（上外附中 / “神仙学校”）

直属国家教育部 · 全国16所具外语类保送推荐资格学校之一 · 初高中七年一贯

身份与学制

  • 学制：初高中七年一贯制；初三须参加本校文化测试，通过者升入本校高中部，未通过者参加上海市中考升入其他学校；
  • 出口：外语类保送、出国为主，兼有高考；
  • 课程：10门外语（英德法日俄西葡意阿希），小班化全外语教学；设英语班、多语种科创班、双外语班、“一带一路”语种班；
  • 2026招生意：本部 240 名；另有上外附中东校（虹口区属独立法人，办学模式与本部同步）120 名；
  • 地址/电话：虹口区中山北一路295号（本部）65420302；东校 虹口天宝路1115号 63575019；
  • 官网/报名：sfls.cn

报名要求（2026官方原文要点）

  • 对象：上海常住户籍；或持有效居住证且父母一方积分达标准分值的应届小学五年级毕业生；
  • 条件：品行端正、综合素质优秀、较好外语素养；身心健康、口齿清楚、无听力障碍；服从语种安排；
  • 流程：4月10–13日线上报名并上传综合素质佐证材料 → 4月15日查初审 → 4月18日评估活动 → 4月20–24日官网公示录取；
  • 评估形式：2025年官方明示为“人机对话”（全程机考，无面谈）；2026年官方未细述具体形式，以“评估活动”表述。
适合谁：外语素养突出、方向明确偏国际/语言，或对科创+多语双修感兴趣的孩子。
注意：①上外附中东校学籍、毕业证均为“东校”独立主体，报考前要分清“本部 vs 东校”两个志愿口径；②近年评估全机考、题量大节奏快，拼的是熟练度与心理素质；③双外语班、语种班为学校统一安排，需服从分配。

上海外国语大学附属浦东外国语学校（上外浦外）

公办寄宿制 · 具外语类保送推荐资格 · 初中4年（含预初）+ 高中3年

身份与学制

  • 学制：初中四年（含预初一年）+ 高中三年；通过学校内部直升考试者升本校高中部，其余参加上海市中考；
  • 出口：外语类保送与高考为主，另有国际课程班（VCE等，高中阶段自主招生）；
  • 课程：英语见长、多语发展（英德法日俄等），小班化全外语授课，可双外语主修；
  • 2026招生意：共 430 名 = 浦东生源 370 名 + 非浦东生源 60 名（2025年浦东名额由290扩至370）；
  • 地址/电话：浦东新区达尔文路91号 58558710；
  • 官网/报名：msshw.pudong-edu.sh.cn

报名要求（2026官方原文要点）

  • 对象：五年级应届毕业生：①上海常住户籍；②居住证+父母一方积分达标；③在沪台胞、港澳永久居民；
  • 条件：品行端正、综合素质优秀、较好外语潜质；口齿清楚、无听力障碍；身心健康、有独立生活能力（寄宿）；
  • 流程：4月10日9:00–4月13日9:00官网登记 → 4月13–15日审核 → 4月16–17日查结果并打印登记表/邀请函 → 4月18日评估 → 发放录取通知；
  • 历史变化：2025年简章曾要求“小学四或五年级获校级及以上荣誉称号”，2026年简章未再单列——硬性条件逐年调整，务必以当年原文为准。
适合谁：外语好、可接受寄宿、家在浦东或愿意来浦东的家庭——浦东生源名额占比大（370/430），是“三公里相对最容易够到的”；非浦东家庭仅60个名额，竞争激烈。
注意：官方未在简章中明确定义“浦东生源”口径（学籍/户籍/居住地？），浦东家庭报名前务必电话或细则确认；评估为全程机考、连续作答不设休息，对耐力有要求。
