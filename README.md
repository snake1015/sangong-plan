# 沪上三公 · 十年上岸规划（2岁半起步版）

为 2 岁半孩子准备的上海“三公”（上海市实验学校 / 上外附中 / 上外浦外）小升初长线规划静态网站。
采用**多页“标签页”结构**：顶部导航每个菜单对应一个独立页面，另有真题模考页与可打印工具包页面。

## 目录结构

```
sangong-plan/
├── index.html            # 🏠 首页：Hero + 生日推算 + 三公是什么 + 两条通路
├── roadmap.html          # 十年路线（03）：8 阶段行动清单（含推算器）
├── action.html           # 落地实操（04）：周节奏模板 + 12个月行动历 + 档案法
├── schools.html          # 三校档案（05）：上实 / 上外附中 / 上外浦外
├── process.html          # 报名流程（06）：每年4月节奏 + 名额对照
├── profile.html          # 上岸配置（07）：官方明文 vs “隐形门槛”
├── resources.html        # 学习资源（08）：考试报名通道 / 免费平台 / GitHub·开源 / 更多渠道
├── practice.html         # 真题模考（09）：官方真题入口 + 站内原创题库（交互练习）
├── tools.html            # 打印工具（10）：6 张模板入口（→ printables.html）
├── faq.html              # FAQ（11）
├── planb.html            # Plan A/B/C/D（12）
├── sources.html          # 来源与免责（13）
├── printables.html       # 可打印工具包（6 张自带分页模板）
├── assets/
│   ├── style.css         # 主样式（含打印样式）
│   ├── tools.css         # 组件样式 + 题库（quiz）样式
│   ├── app.js            # 导航、页签、出生日期推算
│   └── quiz.js           # 原创题库（51 题）+ 练习/模考/错题本引擎
├── _src/
│   ├── index-full.html   # ⚠️ 单一内容源（全章节合集，勿直接部署）
│   └── build.py          # 多页构建脚本：改内容源后运行即可重新生成所有页面
└── README.md
```

另见工作区同级目录 `research/`：调研抓取的三校官方简章与媒体报道原文。

## 日常维护（重要）

本目录是**构建产物**。想改任何内容，请修改 `_src/index-full.html` 后执行：

```bash
python3 _src/build.py     # 重新生成全部 12 个页面（含 practice.html）
```

构建脚本会：按章节 id 抽取内容 → 自动把站内锚点改写为跨页链接 → 生成带“当前页高亮”导航的独立页面。

## 内容特点

- 出生日期推算器在 首页 / 十年路线 / 落地实操 / 报名流程 页顶部：改生日，时间线整体平移；
- **真题模考页（practice.html）**：
  - 官方/公开真题入口（AMC8 · AoPS/MAA、袋鼠数学历年真题、剑桥官方样题、小托福 ETS、CSP/NOIP、蓝桥、上海招考热线、国家中小学智慧教育平台），链接均经核验并标注访问情况；
  - 题库按学段分**两条赛道**（均为非官方真题的原创编写）：
    - 🧸 **幼升小（2.5–6 岁，低龄适配）**：30 题（数感 8 / 观察 6 / 语言 6 / 英语 6 / 常识 4），分「启蒙 2.5–4 岁」与「幼小衔接 4–6 岁」；全部点选作答、按钮与字号加大、**🔊 语音读题**、**⭐️ 星级评价**与鼓励式反馈、不计分的**亲子口语卡**、10 题「亲子小测」；
    - 🎒 **小升初（10–12 岁）**：51 题（数学 19 / 英语 12 / 语文 10 / 综合 10），三公机考风格，含逐题解析、**模拟卷 A（30 分钟）/ B（25 分钟）**；
  - 交互功能：练习模式逐题判分解析、限时交卷、答题卡跳题、成绩历史、**按赛道分开的错题本**（localStorage，本机保存）、答案与解析速查（可打印）；
- 学习资源页含考试报名通道表、免费官方平台、分龄分科“资源使用卡”、GitHub/开源仓库清单与更多信息渠道；
- 可打印工具包在 tools.html 与 printables.html，浏览器打印自动分页。

## 信息口径与免责

- 整理时间：2026 年 9 月。招生数字与流程以 **2025/2026 年三校官方招生简章 + 上观新闻等主流转载** 为准；
- 三校**不公布真题**，市面“三公真题”均为考生回忆版或机构整理；本站题库为原创模拟题，不代表真实考题与难度，也不构成押题；
- 三校每年 4 月上旬更新简章；考试报名渠道逐年变化，务必以官网当期公告为准；
- 海外站点（Scratch / Code.org / 可汗 / Oxford Owl / AoPS / MAA / 剑桥）访问速度取决于网络环境；GitHub 内容请家长先审再用；
- 机构文章与社区帖仅供交叉参考；本站不推荐任何课程，内容不构成教育或法律建议。
