09 · 真题与模考：官方真题入口 + 站内原创题库

先说清楚一件事：三公没有官方真题——学校从不公布试卷，市面上所有“三公真题”都是考生回忆版或机构整理。所以本站分成两部分：① 可合法使用的官方真题 / 样题入口（数学竞赛、英语考试等，质量最高）；② 站内原创题库，按三公机考常见题型风格自编，用来练题感、练限时、练错题归因。

使用顺序建议：G2–G3 用本站题库练“题感与限时” → G4 起用官方真题（AMC8 / 袋鼠 / 剑桥 / 小托福）做真实水平检测 → G5 报名前 8 周每周 1 套全真模考（本站模拟卷或官方真题卷），并把错题二刷。

🕵️ “三公真题回忆版”去哪找？（附防坑）

  • 机构考情回顾：每年 4 月评估结束后，菠萝、犀牛、季遇、x-newedu 等会整理“考生回忆版题型”（见 来源页 已列条目）——看题型与难度趋势即可，别当标准答案；
  • 家长社区：千帆育儿网、小花生里的“上岸帖”常有面谈流程细节，注意区分真实分享与软文；
  • 学校官方渠道：三校官网 / 公众号只发简章与录取名单，不会发真题；
  • 防坑三条：① 任何“内部真题 / 保过名额”都是骗局；② 回忆版常有错漏，别用它背答案；③ 三公评估每年变化（2025 年起全面机考化），用真题练“能力”而不是“背题”。

🧠 站内原创题库 · 交互练习与模拟卷

下面 51 道题全部为本站原创编写（非官方真题），按三公机考常见题型风格设计：数学（数字谜 / 行程 / 计数 / 逻辑）、英语（快问快答 / 语法 / 中译英 / 阅读）、语文（古诗默写 / 文言 / 文学常识）、综合（科学常识 / 生活应用）。支持逐题解析、限时模拟卷（A / B 两套，各 20 题）与错题本（保存在本机浏览器，不上传）。

阶段频率做什么重点

G5 报名前 8 周每周 1 套 / 严格计时全真模考 + 错题重做（本站「错题本」模式）答题节奏、时间分配、错题清零
提醒：本站题目仅为题感与限时训练而编写，难度与真实评估不完全对应，也不构成任何“押题”。评估结果与刷题数量之间没有必然关系——把错题弄懂、把作息和心态养好，比刷数量重要得多。
